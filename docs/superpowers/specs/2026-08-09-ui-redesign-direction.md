- 日付: 2026-08-09
- 状態: **方向のみ合意。実装は Velopack 自動更新の完了後**に着手する。
- モックアップ（案A・確定版）: https://claude.ai/code/artifact/c1bbd455-290b-4e52-bfe5-d35bc83fccc7

## 背景

現UIが「生成物っぽい／Gemini製っぽい」印象。原因は、絵文字アイコン（⚙📁🗑…）、Bootstrap そのままの警告色（黄 `#FFF3CD`／赤 `#F8D7DA`）、原色青 `#007ACC` の多用、余白の不統一（5/10/15混在）、黒背景＋緑文字のログ、古い GroupBox 枠。

## 採用する方向：案A — Windows 11 Fluent 刷新

**構成（情報設計）は現行を維持**し、見た目と一部レイアウトを刷新する。

### ビジュアル方針
- WPF 標準の **Fluent テーマ**を採用し、Win11 純正の見た目＋**ライト/ダーク自動対応**（OS 設定追従）を得る。
- GroupBox 枠 → **角丸カード**。角丸は カード 8px／コントロール 6px 目安。
- 余白は **4 / 8 / 12 / 16** の一貫スケール。
- 絵文字 → **Fluent（Segoe）系の線画アイコン**に統一。
- Bootstrap 配色を廃止し、**アクセント1色**（Win11 ブルー: ライト `#0067C0` 系／ダーク `#4CC2FF` 系）に整理。更新バナーもアクセント寄りの淡色に。
- チェックボックスの一部（最前面固定など）は **トグルスイッチ**へ。

### レイアウト/UX の決定
- **キャプチャボタンにホットキーを常時表示**（例: `Ctrl + Shift + S` をキーキャップ表示）。既存挙動（`MainWindow.Capture.cs:53` で動的設定）を維持しつつ整形。
- 下部を **全幅プレビュー（主役）＋畳んだログ**に再編。ログは**最新2〜3行を常時表示**し（自動クリップボードコピーで流れる直近が見えるように。参考: "Umado"）、「ログを展開」で全文表示。黒背景・緑文字はやめ、控えめなモノスペースに。
- **「上部カット」は現状維持**（アプリ毎に上タブ幅が違うため任意ON＋px指定。文言も「上部カット」のまま — 作者の意図的な機能）。

### 現状のまま良い点（変えない）
- キャプチャ後の 保存/開く/コピー/削除 をプレビュー下に並べる構成。
- 対象選択＋最前面固定をメインですぐ触れる導線。

## スコープ / 段取り
- 実装は別ブランチ（例 `feature/ui-redesign`）で、**Velopack 実装が main に入った後**に開始（両者とも MainWindow を触るため衝突回避）。
- 主に触るのは `MainWindow.xaml`（と付随する `App.xaml` のテーマ設定、細部の code-behind）。イベントハンドラ名は維持して code-behind への影響を最小化する。
